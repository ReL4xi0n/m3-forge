# Admin dashboard

Build the main dashboard of the admin panel for "Shelfwise", an online bookstore.

Show:
- four key numbers for the last 30 days: revenue ($48,210, up 12%), orders (1,284, up 4%), new
  customers (312, down 3%), average order value ($37.55, up 8%);
- a chart of daily revenue over the last 30 days;
- a list of the five best-selling books with cover placeholder, title, author and units sold;
- a table of the ten most recent orders with order number, customer, date, total and status
  (Paid, Shipped, Refunded or Pending), with a way to filter by status;
- navigation to Dashboard, Orders, Books, Customers and Settings;
- a search field and the signed-in admin's avatar.

Make it clear and calm to read, and usable on a tablet as well as a desktop.
